# SkillsWorkshopManagementSystem
A project that was created for a school assignment.


## Project Overview
A Java-based application for managing workshops, participants, and registrations. Features include database operations, report exports (Excel/JSON), and a comprehensive management system.

## Features
- Workshop and participant management
- Registration system
- Search and summary reports
- Excel/JSON export capabilities
- Data persistence
- Database connectivity (JDBC recommended)

## Getting Started
1. Clone the repository
2. Ensure Java 8+ is installed
3. Add required dependencies (JDBC driver, Apache POI for Excel, Jackson for JSON)
4. Compile and run:

## Dependencies
- Java 8+
- JDBC driver (e.g., MySQL Connector/J)
- Apache POI (for Excel export)
- Jackson Databind (for JSON export)
